# PTE Idea Banks

Visual pros & cons maps for PTE Academic essay topics.

## Live site

**https://dunghuynhandy.github.io/pte/**

Remote education: **https://dunghuynhandy.github.io/pte/idea_bank/remote_education/**

## Build

```bash
python3 build_site.py
```

## Add a topic

1. Create `idea_banks/your_topic/index.html` (copy `remote_education/`)
2. Add a card in `build_site.py` → `build_index()`
3. Run `python3 build_site.py` and push
